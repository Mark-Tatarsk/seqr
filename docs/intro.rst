Introduction
============

Welcome to the documentation for **seqr**, a platform for genomic analysis and clinical genomics.

Purpose
-------

seqr is designed to help researchers and clinicians analyze genomic data, specifically focusing on identifying variants that cause rare diseases. It provides a user-friendly interface for filtering, searching, and collaborating on genomic datasets.

Main Features
-------------

*   **Variant Filtering**: Advanced filtering options to narrow down variants based on frequency, inheritance patterns, and functional impact.
*   **Collaboration**: Share cases and findings with other researchers and clinicians.
*   **Integration**: Seamless integration with reference data and external databases like PanelApp and Matchmaker Exchange.
*   **Search**: Powerful search capabilities using ClickHouse for high-performance genomic data querying.
